# Ops QA Portfolio

## Oil & Gas Well Operations Management System

This repository demonstrates an end-to-end Quality Assurance process for a fictional Oil & Gas Well Operations Management System.

The project is created as a professional QA portfolio to demonstrate practical experience in Manual Testing, Test Case Design, Defect Management, Requirement Traceability, Regression Testing, API Testing, and Test Automation.

> Note: This is a fictional portfolio project. No confidential company code, data, credentials, or proprietary information is used.

---

## Project Overview

Ops is a fictional web-based application designed to manage Oil & Gas well information, wellbore configuration, directional survey data, treatment operations, engineering analysis, and operational reports.

The QA activities cover the complete software testing lifecycle from requirement analysis through test execution and release validation.
