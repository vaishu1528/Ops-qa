# Ops QA Portfolio

## Oil & Gas Well Operations Management System

This repository demonstrates an end-to-end **Quality Assurance and Software Testing process** for a fictional Oil & Gas Well Operations Management System.

The portfolio showcases practical QA activities across **Manual Testing, Test Case Design, Defect Management, Requirement Traceability, Regression Testing, API Testing, and Test Automation**.
