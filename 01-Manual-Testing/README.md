# Manual Testing Portfolio

## Overview

This section demonstrates a structured Manual Testing and Software Quality Assurance approach for a web-based Oil & Gas well operations management system.

The portfolio covers the complete QA lifecycle, starting from requirements analysis and test planning through test design, execution, defect management, regression testing, traceability, and test closure.

All application names, users, well identifiers, test data, defect IDs, execution metrics, and business information used in this portfolio are synthetic and created for demonstration purposes.

---

## Manual Testing Lifecycle

Requirements
→ Test Planning
→ Test Strategy
→ Test Data Preparation
→ Test Case Design
→ RTM
→ Test Execution
→ Defect Management
→ Retesting
→ Regression Testing
→ Test Summary
→ Test Closure
